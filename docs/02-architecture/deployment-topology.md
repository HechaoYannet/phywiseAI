# 部署拓扑

## 当前自托管基线

- 反向代理：Nginx 或同类网关。
- `apps/web`: Next.js 进程，负责页面与 BFF。
- `apps/api`: FastAPI 进程，负责解析、Tutor 和仿真 API。
- `SQLite`: 默认持久化题目、工作区和修订。
- 本地文件存储：保存 PDF、图片和预览图。
- 可选 Worker：异步 OCR 和重解析任务。
- 可选 Redis：当 Worker 启用时作为任务队列。

## 扩展拓扑

- Postgres：替换本地 `SQLite`，承载更高并发和更稳的备份策略。
- Redis：承担队列、缓存和短期状态。
- Object Storage：替换本地文件存储，承载大体积 PDF、图片、快照和导出文件。
- 独立 Worker 池：将 OCR、重解析、导出和仿真预计算从 API 进程剥离。

## 原则

- 托管层可替换，业务协议不变。
- 流式响应与多实例缓存由自托管环境自行保证。
- 未来如接入托管平台，只替换部署层，不重写业务核心。
