# 环境变量

## 通用

- `PHYWISE_APP_ENV`
- `PHYWISE_PUBLIC_ORIGIN`
- `PHYWISE_API_ORIGIN`
- `PHYWISE_DATABASE_URL`
- `PHYWISE_STORAGE_ROOT`
- `PHYWISE_STORAGE_BUCKET`
- `PHYWISE_PARSE_EXECUTION_MODE`
- `PHYWISE_REDIS_URL`
- `PHYWISE_PADDLEOCR_ENABLED`
- `PHYWISE_MAX_PREVIEW_PAGES`
- `PHYWISE_TENCENT_SECRET_ID`
- `PHYWISE_TENCENT_SECRET_KEY`
- `PHYWISE_TENCENT_REGION`
- `PHYWISE_VISION_MODEL`
- `PHYWISE_REASONING_MODEL`

## Web

- `NEXT_PUBLIC_API_ORIGIN`

## 原则

- 模型通过适配层接入，不把业务绑到单一厂商。
- 前后端变量分离，浏览器只暴露必要公开信息。
- 本地开发默认依赖 `SQLite + 本地存储 + inline parse`，只有在需要异步任务时才接入 Redis。
