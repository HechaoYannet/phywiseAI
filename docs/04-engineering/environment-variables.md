# 环境变量

## 通用

- `PHYWISE_APP_ENV`
- `PHYWISE_PUBLIC_ORIGIN`
- `PHYWISE_API_ORIGIN`
- `PHYWISE_STORAGE_ENDPOINT`
- `PHYWISE_STORAGE_BUCKET`
- `PHYWISE_POSTGRES_URL`
- `PHYWISE_REDIS_URL`
- `PHYWISE_VISION_MODEL`
- `PHYWISE_REASONING_MODEL`

## Web

- `NEXT_PUBLIC_APP_NAME`
- `NEXT_PUBLIC_API_ORIGIN`

## 原则

- 模型通过适配层接入，不把业务绑到单一厂商。
- 前后端变量分离，浏览器只暴露必要公开信息。
